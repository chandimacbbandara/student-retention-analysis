01 — SYSTEM PIPELINE

Every prediction passes through the same structured pipeline. The goal is to transform raw student information into a reliable three-class prediction.

02 — FINAL MODEL ARCHITECTURE

Four complementary prediction models

The final ensemble combines statistical and tree-based approaches. Each model contributes a different perspective on the student's outcome.

STATISTICAL

A regularised multinomial logistic model using L1 regularisation. It provides a linear and interpretable view of the relationship between predictors and outcomes.

Why use stacking?

The four base models learn different patterns from the same student data. Stacking allows a second-level Logistic Regression meta-learner to learn how to optimally combine their predictions.

  • LASSO contributes a sparse, regularised linear view.
  • Elastic Net provides a second regularised statistical perspective.
  • XGBoost captures nonlinear relationships and feature interactions.
  • Gradient Boosting provides another tree-based view of the student's characteristics.
  • 5-Fold Cross-Validation (cv=5) is used during stacking to generate out-of-fold meta-features and prevent data leakage.
  • The Logistic Regression meta-learner combines these 4 model outputs into the final prediction.
  • The ensemble achieved 77.76% test accuracy and 89.04% ROC-AUC.

05 — MAKING A PREDICTION

What happens when a user enters student information?

The prediction process begins when the user submits a student's information. The trained model then processes the same type of information used during model development.

01

User Input

The user enters the student's demographic, academic, financial and application information.

02

Preprocessing

The saved preprocessing pipeline converts the raw values into the representation expected by the models.

03

Model Inference

The four base models generate predictions and probability estimates for the student.

04

Final Output

The stacking meta-learner combines the model outputs and returns the final predicted outcome.

06 — UNDERSTANDING THE OUTPUT

What does the prediction mean?

The system produces one of three academic outcome classes. The probability distribution provides additional context about the model's prediction.

Dropout

The model predicts that the student's observed characteristics are more consistent with the Dropout class.

Enrolled

The model predicts that the student is more consistent with the Enrolled class at the prediction point.

Graduate

The model predicts that the student's observed characteristics are more consistent with the Graduate class.

Important: The predicted probability is a model estimate, not a guarantee of a student's future outcome. The Enrolled class is especially difficult because it represents students whose eventual outcome has not yet been observed at the prediction point.
